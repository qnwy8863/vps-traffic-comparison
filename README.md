## 大流量VPS，先分清三个参数

看大流量套餐，真正需要核对的只有三样：月流量、端口带宽、计费方向。

**月流量和端口带宽要分开看。** 这两个数字经常被混在同一个表格里，但含义完全不同：月流量决定一个月能传输多少数据，端口带宽决定单文件的下载峰值。举几个已核验的例子：bytevirt 东京套餐给 1.5TB 月流量，端口是 500Mbps；CloudCone 洛杉矶是 4TB 配 1Gbps；akilecloud 洛杉矶那档最大方，10TB 月流量直接配 5000M 端口。同样的流量额度，端口差五倍，高峰期的体验就是两个档次。

**计费方向藏在条款里。** 有的商家只统计单向流量，有的进出都算。locvps 的日本限流量套餐就明确写了按入口/出口双向计算，对下载为主的用法来说，实际能跑的量接近标称的一半。这一条在页面标题上看不出来，下单前得翻条款。

**超量后的处理方式也要确认。** 常见做法是限速或者额外计费，两种都算不上友好，选套餐时最好提前看清自己那一档的处理规则。

## 常见问题

**5TB 月流量到底够不够用？**
5000GB 除以 30 天，每天约 166GB。个人建站、中小团队的文件同步和备份，这个量基本用不完。但要注意：1Gbps 端口满速跑一小时能吃掉约 450GB 流量，5TB 只够满速跑 11 个小时。持续跑大文件任务的，先估算日均传输量再选档位。

**RackNerd 这类年付套餐怎么付款？**
支持支付宝付款，套餐按年付报价。促销档位轮换时价格会有浮动，下单时在结账页确认当前价格和配置即可。

**大流量套餐的速度会不会很差？**
速度由端口决定，流量额度只决定能跑的总量。选套餐时把端口速度单独确认一遍，比如 akilecloud 洛杉矶是 5000M 端口，CloudCone 是 1Gbps，两者流量额度接近，峰值带宽差五倍。

**到底选美国还是日本机房？**
给国内用户访问、延迟敏感，选日本软银或 IIJ 线路，接受流量小、单价高；自己用、跑任务、下载数据，选美国机房的大流量年付套餐，同样的预算流量能多拿几倍。
